# Repository Instructions

## Mission and safety boundary

Maintain a reproducible factor-research and artifact-audit package for prediction markets. Never place live orders or overstate backtest associations as scalable trading profits.

## Research integrity

- Report both raw $\Delta p$ IC and price-neutral IC (residualized on $[1, p, p^2]$).
- Compute short-leg returns using the NO-token cost basis $(1 - p)$, never $p$.
- Keep in-sample combination selection distinct from held-out factor orientation tests.
